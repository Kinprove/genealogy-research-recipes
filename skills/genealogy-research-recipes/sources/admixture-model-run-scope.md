## Sources

All sources are threads on the GenArchivist Forum. Where a thread start date is not shown, that is stated.

- **S1:** [Excessive Yemeni/Peninsular Arab DNA in fully NW European?](https://genarchivist.net/showthread.php?tid=2476), started 2026-03-31. Used for: the penalty-and-removal sequence with distances at each stage, the regional-only fit, and an offer to check for drift on a PCA plot.
- **S2:** [G25 Calculator - Modern K99](https://genarchivist.net/showthread.php?tid=2463), started 2026-03-24. Used for: labels built by clustering, combined label names, fixed-range components, removing populations that cause overfitting, and one participant's distance rule of thumb.
- **S3:** [K97 Modern (K99 "version 2")](https://genarchivist.net/showthread.php?tid=2489), started 2026-04-07. Used for: repeat single-mode runs that vary, near-tied Oracle slivers, fixed components and an ADC comparison.

- **S5:** [White American State Averages K15](https://genarchivist.net/showthread.php?tid=2426), start date not shown. Used for: K15 components described as a calculator effect, their absence in a rerun that both added references and changed mode, and the K15 distance scale.
- **S6:** [Ashkenazi Jewish Origins Thread](https://genarchivist.net/showthread.php?tid=558), started 2024-02-19. Used for: swapping in a closer local reference, and a control person of known ancestry who needed a balancing source.

- the component status terms (reference-gap artefact / model-dependent / possible proxy / stable within tested scopes / uninterpretable);

- the worked reruns and their paired distances;
- the posted qpAdm specifications and figures;
- the reported provider category description;
- the locality correction;
- participants' observations about sims, scaling, releases and software behaviour.
