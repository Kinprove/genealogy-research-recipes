- **S2:** [LitvakSIG, MyHeritage Welcome](https://www.litvaksig.org/welcome-to-myheritage-visitor/). Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. The data provider directs users to its All Lithuania Database and the separate Vilnius project.

- **S3:** [LitvakSIG, Vilnius Household Registers](https://www.litvaksig.org/research/special-projects/vilnius-household-registers). Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. Read the geographic and chronological scope and project’s batch-based indexing instructions.

- **S4:** [LitvakSIG, Lithuanian Central State Archives](https://www.litvaksig.org/information-and-tools/archives-and-repositories/lithuanian-central-state-archives). Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. Provider describes LCVA custody of the Vilnius household registers and the historical jurisdiction.

- **S5:** [MyHeritage Adds 43 Million Historical Records in September 2023](https://blog.myheritage.com/2023/10/myheritage-adds-43-million-historical-records-in-september-2023/), published 2023-10-03. - **S6:** [MyHeritage, Lithuanian-Jewish Household Registers from LitvakSIG, 1835–1946](https://www.myheritage.pl/research/collection-20672/lithuanian-jewish-household-registers-from-litvaksig-1835-1946?legacyCategoryCollectionUrl=1). Reviewed 2026-11-22, catalogue, access read. Read 2026-11-22. The public collection page opened in Polish and confirmed the provider, advertised span, birth and residence fields, parents’ names and geographic scope. The source check used the collection description.

- **S7:** [MyHeritage, Lithuanian-Jewish Revision Lists from LitvakSIG, 1795–1942](https://www.myheritage.com/research/collection-20670/lithuanian-jewish-revision-lists-from-litvaksig-1795-1942). Reviewed 2026-11-22, catalogue, access read. Read 2026-11-22. The public collection page confirmed the provider, advertised span, indexed birth and residence details and father’s name. The source check used the collection description and public search form.

- **S8:** [LitvakSIG, Revision Lists and Other Census Lists](https://www.litvaksig.org/information-and-tools/archives-and-repositories/revision-lists-and-other-census-lists). Reviewed 2026-11-22, web-page, access read. Read 2026-11-22. The data provider identifies 1858 as the final imperial revision, describes later family lists and explains that official registration and physical residence could differ.
