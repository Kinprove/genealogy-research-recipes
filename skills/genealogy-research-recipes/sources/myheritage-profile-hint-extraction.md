# Sources for Review a MyHeritage profile Hint before copying facts or relatives

- **S1:** [New: Extract information from Hints to your tree directly from the profile pages](https://blog.myheritage.com/2024/08/new-extract-and-save-information-to-your-tree-directly-from-the-profile-pages/), published 2024-08-21. Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. Used the profile Hint workflow for source review, highlighting, old values, editing, reverting, citations and selective additions.

- **S2:** [MyHeritage, How do I save a record from the historical records search engine?](https://www.myheritage.com/help/en/articles/12852043-how-do-i-save-a-record-from-the-myheritage-historical-records-search-engine). Reviewed 2026-11-18, help-page, access read. Read 2026-11-18. Current provider help describes the linked reference and profile display after saving a historical record.

- **S3:** Éric Bousquet, [From the Amalfi Coast to Sète: How I Found My Long-Lost Cousins Thanks to MyHeritage](https://blog.myheritage.com/2025/06/from-the-amalfi-coast-to-sete-how-i-found-my-long-lost-cousins-thanks-to-myheritage/), published 2025-06-26. Reviewed 2026-11-20, web-page, access read. Read 2026-11-20. In this guest account, Bousquet reports finding his great-grandmother listed in a matched tree and messaging its owner through MyHeritage. He also reports using a separate tree match to find another branch of the family that emigrated. The known-relative starting point is adapted from this account.

- **S4:** [MyHeritage Discoveries Pages](https://education.myheritage.com/article/myheritage-discoveries-pages/). Reviewed 2026-11-21, web-page, access read. Read 2026-11-21. Provider documentation describes the close-family comparison in Smart Match review, explains why matches with no new information can still be useful, and documents the Discoveries views and match type and status filters.

- **S5:** [MyHeritage, Can I send a message to another site manager via a Smart Match?](https://www.myheritage.com/help/en/articles/12851256-can-i-send-a-message-to-another-site-manager-via-a-smart-match), published 2026-07-21. Reviewed 2026-11-20, help-page, access read. Read 2026-11-20. Provider help documents the Contact control on the matching site manager’s name in the person’s Smart Matches list and states that access depends on the account’s subscription.

- **S6:** Erica Edvi, [Introducing All-New Profile Pages With Hints](https://blog.myheritage.com/2024/02/introducing-all-new-profile-pages-with-hints/), published 2024-02-29. Reviewed 2026-11-21, web-page, access read. Read 2026-11-21. The provider’s desktop launch post documents the profile Matches tab for pending matches, side-by-side review, and Hint display settings shared with the family tree. Public documentation review only.

- **S7:** Melina Papadopoulos, [MyHeritage for Free: 10 Tips for Using It Without a Subscription](https://familytreemagazine.com/websites/myheritage-for-free/), updated 2026-08-17. Reviewed 2026-11-21, web-page, access read. Read 2026-11-21. Papadopoulos suggests using Discoveries to group matches and filter by review status. S4 supplies the exact view names and distinguishes matches to trees from matches to records.

- **S8:** Marie Cappart, [5 Ways to Make Progress with Your Genealogy Even When You’re Sick](https://blog.myheritage.com/2022/08/5-ways-to-make-progress-with-your-genealogy-even-when-youre-sick/), published 2022-08-23. Reviewed 2026-11-21, web-page, access read. Read 2026-11-21. Cappart suggests opening Discoveries in the app and narrowing it by match type. S9 supplies the current filter control and review steps.

- **S9:** [MyHeritage, How can I check Smart Matches and Record Matches using the MyHeritage app?](https://www.myheritage.com/help/en/articles/12851444-how-can-i-check-smart-matches-and-record-matches-using-the-myheritage-app), published 2026-07-21. Reviewed 2026-11-21, help-page, access read. Read 2026-11-21. Provider help documents the upper-right filter for Smart Matches or Record Matches and the controls for opening a person’s matches and reviewing them.

- **S10:** Daniella Levy, [I Found My Long-Lost German Relatives and an Unknown Half-Great-Uncle Thanks to MyHeritage](https://blog.myheritage.com/2023/02/i-found-my-long-lost-german-relatives-and-an-unknown-half-great-uncle-thanks-to-myheritage/), published 2023-02-15. Reviewed 2026-11-21, web-page, access read. Read 2026-11-21. Laetitia Renault reports finding sibling names through a Record Match and tracing one sibling’s descendants. She separately reports a Filae Smart Match that followed a different line from her great-grandfather through a child of his first marriage. Her tree already included the marriage.
