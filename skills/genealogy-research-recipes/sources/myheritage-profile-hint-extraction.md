- **S2:** [MyHeritage, How do I save a record from the historical records search engine?](https://www.myheritage.com/help/en/articles/12852043-how-do-i-save-a-record-from-the-myheritage-historical-records-search-engine). - **S3:** Éric Bousquet, [From the Amalfi Coast to Sète: How I Found My Long-Lost Cousins Thanks to MyHeritage](https://blog.myheritage.com/2025/06/from-the-amalfi-coast-to-sete-how-i-found-my-long-lost-cousins-thanks-to-myheritage/), published 2025-06-26. He also reports using a separate tree match to find another branch of the family that emigrated. The known-relative starting point is adapted from this account.

- **S4:** [MyHeritage Discoveries Pages](https://education.myheritage.com/article/myheritage-discoveries-pages/). Reviewed 2026-11-20, web-page, access read. Read 2026-11-20. Provider documentation describes the close-family comparison in Smart Match review and explains why matches with no new information can still be useful.

- **S5:** [MyHeritage, Can I send a message to another site manager via a Smart Match?](https://www.myheritage.com/help/en/articles/12851256-can-i-send-a-message-to-another-site-manager-via-a-smart-match), published 2026-07-21.
