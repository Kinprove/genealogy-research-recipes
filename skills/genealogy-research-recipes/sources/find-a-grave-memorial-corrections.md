# Sources for Correct a Find a Grave memorial or request its management

- **S1:** [Fact-Checking Find a Grave Memorials: Tips for Genealogists](https://familytreemagazine.com/websites/fact-check-find-a-grave/), published 2025-10-16. Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. Used the author’s distinction between suggestions and a request to take over management.

- **S2:** [Find a Grave, Sending Suggest Edits and Notes](https://support.findagrave.com/hc/en-us/articles/53933460430995-Sending-Suggest-Edits-and-Notes). Reviewed 2026-11-18, help-page, access read. Read 2026-11-18. Site instructions for proposing edits, providing a note and sending a suggestion to the manager.

- **S3:** [Find a Grave, Request to Manage](https://support.findagrave.com/hc/en-us/articles/53933435435283-Request-to-Manage). Reviewed 2026-11-18, help-page, access read. Read 2026-11-18. Site instructions distinguish member-managed memorials and those managed by Find a Grave and describe transfer guidelines.

- **S4:** [The Do’s and Don’ts of Find a Grave](https://familytreemagazine.com/cemeteries/the-dos-and-donts-of-find-a-grave/), published 2025-09-23. Reviewed 2026-11-22, web-page, access read. Read 2026-11-22. The author recommends using memorial IDs to link relatives and keeping a contact route open for transfer requests. Find a Grave’s help describes the link direction and distinguishes profile contact settings from the memorial’s Contact Manager form.

- **S5:** [Find a Grave, Family Members](https://support.findagrave.com/hc/en-us/articles/53933375214355-Family-Members). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Site instructions identify the Memorial ID, the parent and spouse fields, the direct and suggested edit paths, and how child links and spouse links display reciprocally.

- **S6:** [Locating Tombstones at Find a Grave | Website Tutorial](https://www.youtube.com/watch?v=Ruj0khFhjYQ), published 2025-09-26. Reviewed 2026-11-22, video, access partial. Read supplied transcript excerpts 2026-11-22. The video page did not open. The excerpts show Sunny Jane Morton demonstrating family links, document images through Add Photos and the Contribute route to sent edits. Find a Grave’s help documents the current procedures.

- **S7:** [Find a Grave, Suggest Edits](https://support.findagrave.com/hc/en-us/articles/53933424659475-Suggest-Edits). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Site instructions cover suggested field changes, Save Suggestions and the sent-edit queue, including lookup by memorial ID.

- **S8:** [Find a Grave, Management Questions](https://support.findagrave.com/hc/en-us/articles/53933343565459-Management-Questions). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Site instructions locate the Suggested Edits screen on Contribute and at the pencil icon.

- **S9:** [Find a Grave, Add a Photo](https://support.findagrave.com/hc/en-us/articles/53933375335059-Add-a-Photo). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Site instructions cover selecting and uploading an image from a memorial page and explain how the contributor is credited.

- **S10:** [Find a Grave, Types of Photos](https://support.findagrave.com/hc/en-us/articles/53933315325459-Types-of-Photos). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. The site lists documents related to the person under the Other photo type.

- **S11:** [Find a Grave, Account Settings](https://support.findagrave.com/hc/en-us/articles/53933329123731-Account-Settings). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Site instructions cover enabling profile messages, changing the account email and controlling its display.

- **S12:** [Find a Grave, Profile Pages](https://support.findagrave.com/hc/en-us/articles/53933408684947-Profile-Pages). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Site instructions distinguish profile messaging and optional email display from the memorial’s Contact Manager form, which can still carry a transfer request when both profile routes are off.
