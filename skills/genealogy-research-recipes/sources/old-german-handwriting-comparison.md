# Sources for Test a reading of an old German handwritten word

- **S1:** [Translating Old Genealogy Records: 20 Top Tools](https://familytreemagazine.com/resources/genealogy-translation-tools/), published 2025-05-20. Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. Used the author’s advice to compare a word with the Schrift-Generator, and use Archion and BYU script examples before translation.

- **S2:** [Archion, Church Books](https://www.archion.de/en/discover-archion/church-books). Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. Archive platform’s description of scripts, alphabet tables, exercises and mixed Latin and Gothic usage.

- **S3:** [Alte Deutsche Handschriften, Schrift-Generator](https://www.deutsche-handschrift.de/adsschreiben.php). Reviewed 2026-11-18, web-page, access read. Read 2026-11-18. Tool page shows the word input, script comparison options and output controls.

- **S4:** [Brigham Young University, German Script Tutorial practice sheets](https://script.byu.edu/00000183-5c5d-d961-afa7-fedf51dd0000/german-english-handwriting-practice-sheets). Reviewed 2026-11-18, pdf, access read. Read 2026-11-18. Opened the downloadable practice sheets; the interactive test itself returned HTTP 403.

- **S5:** [Předcůvky, Jak začít pátrat po předcích, 6. díl](https://predcuvky.opinio.cz/jak-zacit-patrat-po-predcich-6-dil), published 2024-07-10. Reviewed 2026-11-22, web-page, access read. Read 2026-11-22. The author suggests using known words as letter samples, checking later Latin-script registers and indexes for local names, working back from legible endings, tracing candidate surnames by hand, and including an attempted reading when asking for help. The article distinguishes Czech and German Neo-Gothic cursive and describes a German-language 1876 birth entry in Radkov as a late example of Kurrent. Its linked image did not load. S6 and S7 supply the historical basis for selecting comparison scripts.

- **S6:** [CzechEncy, Dějiny českého písma](https://www.czechency.org/slovnik/D%C4%9AJINY%20%C4%8CESK%C3%89HO%20P%C3%8DSMA). Reviewed 2026-11-22, web-page, access read. Read 2026-11-22. The paleography entry identifies Kurrent as German Neo-Gothic cursive and describes the gradual convergence of Czech and German letterforms by the late eighteenth century.

- **S7:** [Bohdan Kaňák, Rozvinuté německé novogotické písmo](https://pvh.historie.upol.cz/artkey/pvt_00H_0000_28_Rozvinute_nemecke_novogoticke_pismo.php). Reviewed 2026-11-22, web-page, access read. Read 2026-11-22. The Palacký University tutorial describes the shift from Kurrent to humanistic handwriting in Czech-language texts in the 1850s and its continued use in German-language writing.

- **S8:** [Margarete Mücke, Kurrentschriften: Schreiblehrgänge](https://www.kurrent-lernen-muecke.de/lehrgang.php). Reviewed 2026-11-22, web-page, access read. Read 2026-11-22. The course author’s page distinguishes handwritten Kurrent from printed Fraktur and describes the Kurrent writing exercises and historical handwriting samples.

- **S9:** [Genealogie, Čtení starých materiálů](https://genealogie.taby.cz/viewforum.php?f=41). Reviewed 2026-11-22, forum, access read. Read 2026-11-22. The forum’s own posted rules ask for the scan link or hosted image, the entry’s position, and an attempted reading in the original language. For a single word, they ask the poster to identify it and transcribe a few surrounding words.
