# Sources for Build and verify an Ancestry Pro Tools tree worklist

- **S1:** [Mastering Ancestry Pro Tools – An Interview with Gena Philibert-Ortega | Best Websites](https://www.youtube.com/watch?v=FHnaTOOWMGE), published 2024-04-16. Reviewed 2026-11-18, video, access unknown. Opened the video URL on 2026-11-18 but playback or the full transcript was not accessible. Used the supplied transcript excerpt to identify the interviewee’s locality, common-tag and chart ideas and the presenter’s suggested use of Tree Checker.

- **S2:** [Ancestry, Smart Filters in Ancestry Pro Tools](https://redir.ancestry.help/hc/en-us/articles/53933269993363-Smart-Filters-in-Ancestry-Pro-Tools). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Documents the All People filters for error types, events, places, dates, family lines and standard and custom tags. The list has no download or print function.

- **S3:** [Ancestry, Tree Mapper in Ancestry Pro Tools](https://help.ancestry.com/hc/en-us/articles/53933348446355-Tree-Mapper-in-Ancestry-Pro-Tools). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22 via the support redirect. Documents the tree-view path, direct-line default, filters and the count of people represented by each numbered circle. The help page explains the circle counts and gives no color key for green shading.

- **S4:** [Ancestry, Charts and Reports in Ancestry Pro Tools](https://redir.ancestry.help/hc/en-us/articles/53933269892627-Charts-and-Reports-in-Ancestry-Pro-Tools). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Documents report types, focus person, the two-to-seven generation range where offered, preferred-parent scope, download, and saving a printed fan view to a local PDF.

- **S5:** [Ancestry, Tree Checker in Ancestry Pro Tools](https://redir.ancestry.help/hc/en-us/articles/53933315030419-Tree-Checker-in-Ancestry-Pro-Tools). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22 via the support redirect. Documents owner and editor access, the minimum tree size, the homepage shortcut's tree selection, profile controls and causes of empty results. Ancestry says the possible-errors list cannot be downloaded or printed.

- **S6:** [Ancestry, MyTreeTags](https://redir.ancestry.help/hc/en-us/articles/53933347891091-MyTreeTags). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Documents the person card's tag controls, standard and custom labels, and tag visibility.

- **S7:** [Ancestry, Finding People in Your Tree](https://redir.ancestry.help/hc/en-us/articles/53933302364691-Finding-People-in-Your-Tree). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Documents the Find in tree path to List of all people.

- **S8:** [Ancestry, Printing a Family Tree](https://help.ancestry.com/hc/en-us/articles/53933288216083). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22 via the support redirect. Documents the three standard layouts, the Print command and the visible-only scope of its output.

- **S9:** [Ancestry, Ancestry Hints for the Wrong Person](https://redir.ancestry.help/hc/en-us/articles/53933332610067-Ancestry-Hints-for-the-Wrong-Person). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Documents hints for the wrong person and comparing the record with facts and people in the tree.

- **S10:** [Ancestry, Tree Insights in Ancestry Pro Tools](https://help.ancestry.com/hc/en-us/articles/53933322290323-Tree-Insights-in-Ancestry-Pro-Tools). Reviewed 2026-11-22, help-page, access read. Read 2026-11-22. Documents the homepage path, reuse of the last eligible tree and the marriage-age ranking. The help page gives no instructions for a family-line filter.
