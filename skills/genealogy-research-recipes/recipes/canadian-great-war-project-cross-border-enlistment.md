# Find a cross-border enlistment in the Canadian Great War Project

Search for a possibly U.S.-born Canadian Expeditionary Force volunteer and confirm the candidate in the original service file.

## Search for the volunteer

Treat birthplace and citizenship as separate questions. Start at the Canadian Great War Project search form with the known surname and forename. According to the presenter, try USA and United States separately when filtering by reported birthplace [S1† @2026-11-21]. Verify the available fields in the search form and retry without the birthplace constraint before interpreting a miss. Some U.S. volunteers gave a different name or birthplace on enlistment. [S2 @2026-11-21] [S3 @2026-11-21]

## Test possible links in the personnel file

According to the presenter, when testing a co-enlistment lead, try the known enlistment date with the name fields blank, using birthplace as an optional constraint where those fields are available [S1† @2026-11-21]. Compare hometown, age and occupation. Carry each distinct candidate’s regimental number or officer rank into the Library and Archives Canada personnel search. Read the attestation and service file and require separate kinship evidence before linking two people who enlisted together. [S2 @2026-11-21] [S3 @2026-11-21]
