# Recipe: Verifying archival images, case boundaries and search coverage

Use when an image, transcription, catalogue or name index disagrees with another copy, or when reporting that a case was completely inspected. This recipe verifies the source and the inspected scope; identity conclusions belong to [evidence-proof-judgment.md](evidence-proof-judgment.md).

## Separate the objects before counting them

Keep the archival case/volume, digital file or image group, index record, and person distinct. Record the archive/fund/inventory/case, film or DGS, item or digital part, viewer image, and printed page or leaf/verso in separate fields. Preserve identifiers literally before adding a proposed mapping.

For a transcript, retain its image/leaf binding, version or timestamp, and whether human correction is established. Manually triggering recognition still produces machine text. An unavailable newer version neither makes an older transcript current nor disproves its readings. Identify the text actually consulted and its unchecked relationship to the image.

If an original register is unavailable but separately prepared transcriptions are available,
compare their entries and stated record-type coverage for the same target name and period.
Retain both derivative locators, their claimed common original and unresolved discrepancies
or bindings. One transcript's silence does not establish that the original omitted an event;
agreement between copies is not independent corroboration. Family Locket's example describes
a marriage present in a handwritten transcription but absent from a typed one, while the
one-person-or-two question remained open. [S7]

FamilySearch distinguishes image numbers, record pages, household numbers and family numbers. Its item-grouping instructions allow multiple books on a film and a book split across films. A film's image count therefore cannot establish a particular case's boundaries. [S1, S2]

For the requested item, inspect opening and closing material and representative interior pages. Reconcile its covers, title boards, headings, foliation and entries with the catalogue. A readable copy's own page count is not independent evidence that it contains the whole case. If an inventory, certification or other copy establishes a boundary, cite that evidence; otherwise report inspected pages with completeness unresolved.

When a supplied archival image package includes a repository-produced HTML companion, retain
it beside the images. It may preserve the archival signature, reported image count, repository
link and received usage statement that image filenames omit. Bind it to the stated unit and
apply the existing extent checks separately. The [NRW archive download description](https://www.compgen.de/2025/10/landesarchiv-nrw-mit-neuen-digitalisaten-und-downloadmoeglichkeiten/)
motivates retaining that source object; a stated count does not establish complete coverage.

## Catalogue disagreements and reading order

If a copy-holder's short catalogue description leaves several possible originating files,
inspect an actually available fuller catalogue representation and the copy's title board.
Keep the copy item/film key and proposed original repository/signature separate; bind only
the supported original unit and inspected copy extent. The [CAHJP copy example](https://forum.j-roots.info/viewtopic.php?f=153&t=1225)
describes a fuller MARC record, without establishing current fields or controls. A selected-city
copy can be a fragment of the original case; leave an unsupported binding unresolved.

Classify a disputed number before correcting it: archive case, old office reference, volume, act, page or leaf. An old cover and a current inventory can use different identifiers for the same physical object. Preserve both readings and seek their binding; a numerical pattern on neighbouring covers only suggests a mapping. Read struck-out and replacement labels together. A deciphered digit alone does not settle current catalogue attribution.

Check sequence independently from totals. Compare foliation, headings and entries continuing across pages, including transitions between digital parts. Repeated page labels can represent recto/verso, restarted numbering or another section. A complete image set can still be in the wrong order. Do not renumber or merge items from filenames alone.

Before jumping through an unindexed group, inspect title/end cards and readable internal
labels to establish its arrangement and direction. An end-of-roll card at the first image
is a clue to check for reversed order. Within a section whose observed labels support an
ordered run, retain the labeled positions and use progressively smaller forward/backward
jumps toward the target label. Recheck the arrangement at section changes; if labels are
inconsistent or the material is loose, use a bounded sequential inspection instead. Save
the anchor locators and ranges actually inspected: jumping over images does not search
them or establish that a target is absent. The map-roll demonstration motivates this
navigation aid, without verifying the original roll or any household location. [S6]

When a folded letter, card or overlay conceals part of an entry, inspect adjacent frames
for another exposure with it opened or lifted. Confirm that both images show the same
item, retain both locators and distinguish the as-found view from the revealed text.
A repeated exposure is a possibility to check, not a guarantee that hidden text was
captured. If none is available, retain the obscured area as an inspection gap. [S5]

For an unnumbered verso, inspect the actual preceding recto and surrounding sequence before
assigning a leaf/verso binding; leave it unresolved when that context is missing. A film-end
card directing continuation on another reel leaves that part queued until inspected. Keep
printed page, original folio and viewer frame separate rather than deriving one with a fixed
ratio. The [evacuation-film examples](https://forum.j-roots.info/viewtopic.php?f=197&t=1199)
sharpen the sequence check without establishing that the reported images are complete.

When an index points into an earlier image set, locate a known entry or heading in both
versions and retain its old/new coordinates before reusing the pointer. Added or removed blank
and duplicate frames can break a fixed offset. Leave the conversion unresolved if the needed
version is unavailable; an absent film field does not prove that no film exists. The
[Lithuanian image-set example](https://forum.j-roots.info/viewtopic.php?f=164&t=1202)
motivates this version-specific anchor check.

## Report coverage as pages × targets

For each assigned page, retain its source locator, target-name set, inspected area, readable portions and findings. Distinguish:

- inspected and readable for the target;
- inspected with a specific unreadable area;
- unavailable or not inspected.

A completed reader session establishes execution coverage, not transcription accuracy. A new surname was not searched merely because its pages occurred in an earlier sweep for other names. Reconcile existing page/target coverage before repeating or expanding work. For a visual-only request, inspect images; OCR candidates can be a separately labelled channel only when compatible with the requested method.

## Adjudicate each field against the image

Open a native-resolution passage with preceding words, the complete entry and any continuation line. Keep the full page for headings and context; a tight surname crop can conceal the given name or patronymic. Distinguish an entry's subject from an owner named inside an address, witness, institution or place.

Keep literal readings, uncertainty and normalized values separate. Confirmation of a surname does not confirm guessed initials or parentage. A readable patronymic supplies the stated paternal name, not a unique father. A clearly printed impossible date remains a literal reading with normalization unresolved.

When readers or the user disagree, compare the same strokes field by field. Preserve the attributed correction and superseded draft, then update the parent assessment so rejected readings do not return in later summaries. Apply the dependency review in [evidence-proof-judgment.md](evidence-proof-judgment.md) if a corrected field changes an identity hypothesis.

For manual review, provide the exact full source page, citation and neutral question; add a crop as a supplement. Multiple questions can use stable codes. Preparing a review packet does not resolve its questions.

## Scan availability and index coverage are different questions

A catalogue entry, a working scan and a searchable name index establish different things. Verify the actual file and case/part correspondence; a repository page or predicted filename alone does not prove scan availability. A failed retrieval leaves availability unknown.

For JewishGen Ukraine, follow the current Ukraine RD FAQ to its monthly/cumulative upload listings. Compare the actual file reference, years, locality and record type; retain the inspected row and listing date. The FAQ describes periodically updated upload lists, not a guarantee of complete transcription of every case subsection. A missing row does not establish permanent non-indexing. [S3]

An upload for a case does not establish that its supplementary, merchant or other subsection was completely indexed. Resolve that narrower question against a stated coverage scope or the relevant source entries. Index records, people, households and scan pages have different denominators; equal totals do not prove completeness. Preserve the original's locator for each indexed entry, as JewishGen's transcription guidance requires. [S4]

Deliver the literal passage and verified fields, the exact inspected locator, coverage actually achieved and remaining gaps. For OCR retrieval use [corpus-seeded-name-search.md](corpus-seeded-name-search.md); for household reconstruction use [jewishgen-search-family-reconstruction.md](jewishgen-search-family-reconstruction.md).
