# Find the civil register for a historical Ilfov locality

Use this recipe for historical births, marriages and deaths in Ilfov when the register is hard to locate or the historical place name differs from the catalogue heading. A locality’s advertised year span is a finding aid. Verify the year in the register for the event type.

## Find the historical locality

Start with Genealogica’s alphabetical Ilfov guide. Open the locality page, or use the Ilfov external-register listing’s Hartă view to identify a candidate by geography. Open the candidate’s external sources and check the historical locality labels. [S1 @2026-11-22] [S2 @2026-11-22]

For Buda, use the Cornetu listing and check the entries titled Cornetu din Vale/Buda-Cornetu. For Dărăști, open Dărăști-Ilfov and match the historical commune in the register entry. Confirm the village in the book before transferring any entry to the family timeline. [S1 @2026-11-22] [S3 @2026-11-22] [S4 @2026-11-22]

## Check the volume and bound any gap

Copy each listed year run separately. Within the external links, select the event type: născuți for births, căsătoriți for marriages and morți for deaths. Follow the link to the archive entry and match its call number, locality, event type and year. If a year falls between runs, log the gap in that listing and leave the event unresolved. Check the historical Ilfov state archive guide under Registre stare civilă — județul Ilfov for an additional inventory lead. [S1] [S3] [S4] [S5]

For example, the Dărăști-Ilfov locality range starts in 1886, while its listed birth volume IF-F-00014-16-0683 starts in 1891. [S4 @2026-11-22]

## Return the search scope

Record the historical and catalogue place names, the event type and year, the register’s call number and pages inspected, and any missing or unread volume. Use [historical place names](historical-place-name-resolution.md) when the registering commune remains uncertain and [archival image coverage](archival-image-coverage-verification.md) for an unverified link or missing pages.
