# Recover and read a Southern Claims Commission case file

Use this recipe for a Civil War-era property or supply claim by a Southern Unionist. Find the claimant in the consolidated index before choosing a disposition-specific file series.

## Start from the consolidated index

According to the presenter’s advice for a Quaker claimant, search across allowed, disallowed and barred claims. [S1†]

Use the consolidated claimant index on M87 roll 14. Record the spelling, state, office number, report number and disposition before opening a file. Use the disposition to select the record group below. [S2 @2026-11-18]

## Route by the actual disposition

Read **barred** as submission after the 3 March 1873 deadline, so the claim did not receive consideration. Look in M1407 in surname order for the barred case file in Record Group 233. [S2 @2026-11-18]

Read **disallowed** or **dismissed** as a denial. Read the commissioners’ recommendation for the reason. Look in M1407 by report number, then office number, for the disallowed case file in Record Group 233. [S2 @2026-11-18]

Read **allowed** as approval and payment in whole or in part. Use the state, county and claimant’s name to find the *Settled Case Files for Claims Approved by the Southern Claims Commission, 1871–1880* in Record Group 217 (Entry A1-732, Archives identifier 566157). Capture the amounts claimed, allowed and receipted separately when the file gives them. [S2 @2026-11-21]

If a disallowed House file contains only an envelope, check it for a Court of Claims referral. [S4 @2026-11-21] If the House file documents a referral or M87 marks a barred or disallowed claim “C. of C.”, get the court case number from the M2007 docket cards. Use that number in the congressional jurisdiction case files in Record Groups 123 (Archives identifier 2734730) and 205 (3432865). [S2 @2026-11-21]

According to the presenter’s advice, check Fold3 for both paid and unpaid claims. [S3† @2026-11-21] Open *Southern Claims Commission Approved Claims, 1871–1880* for allowed claims and *Southern Claims – Barred and Disallowed* for M1407. If the online search comes up empty, use the archival series for the claim’s disposition. [S2 @2026-11-21] [S5 @2026-11-21]

## Separate the testimony from the ruling

According to the presenter, the witness statements are the place to look for accounts of Union sympathies and wartime events, and a claim file may omit the claimant’s Quaker affiliation. [S1†]

Start with each deposition or testimony heading. Record the speaker, their relationship to the claimant if given, and what they say they saw or knew. Compare each account with the petition, exhibits and final recommendation. Keep religious affiliation open if the testimony does not state it. [S2]

According to Robyn Smith’s advice, include witnesses who gave testimony outside the main hearing. [S6†] Look in the case file for depositions taken by a local special commissioner. [S7] Use the completed certification to record the place, date and officer. A form headed Washington, D.C., can record a hearing held in Mobile, Alabama. [S8]
