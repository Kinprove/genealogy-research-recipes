# Recover U.S. service records for the Mexican border and Punitive Expedition

## Classify the service clue

Establish border duty, duty at Veracruz and service inside Mexico as separate hypotheses. The presentation (only transcript excerpts read) points to the two-part archival guide [S1]. Use Part 1 of the National Archives *Prologue* guide for the operations and Part 2 for archival entries. In a state archive search, combine the unit or state with *Mexican Border* or *Punitive Expedition* and restrict the date to the relevant early twentieth-century service window so results for the 1846–1848 war stay separate. For images and context, start with the Library of Congress exhibition’s Pershing Expedition section. [S2], [S3], [S4]

## Work from medal or badge to recipient

Read the award name and branch inscription before using it to classify service. Distinguish the Navy and Marine Corps inscriptions on the Mexican Service Badge and check that award’s qualifying operation, including possible service in the 1911 maneuvers or at Veracruz. Treat the Mexican Border Service Medal as a lead to qualifying border service and verify the recipient’s actual station before placing them in Mexico. [S2], [S3]

Search RG 92 entry 256 by recipient name. If you have an Army medal serial number, use entry 283 for a Mexican Service Badge numbered 1–25,000, or entry 285 for a Mexican Border Service Medal numbered 2,401–34,060. Keep award type, serial, recipient and unit together in the result. [S3]

## Choose records by branch and command

For a Navy vessel, use RG 24 entries 118 and 134 for deck logs and muster rolls. For Navy or Marine operational correspondence, reports and casualties, use RG 45 subject file W.E. For Marines at Veracruz, start with the RG 127 muster rolls identified as entry 101 and follow [Marine Corps muster and unit records](us-marine-corps-muster-and-wwi-unit-records.md) for the individual’s dated assignment. [S3]

For continental commands, use RG 393. In Part III use the El Paso District index, entry 133, to reach general correspondence in entry 135, including reports on the Glenn Springs raid. For overseas organizational records move to RG 395: entries 1175–1184 cover Veracruz and entries 1185–1229 cover the Punitive Expedition. [S3]

## Trace correspondence and reports by file

In RG 94 search the name and subject index in entry 27 for correspondence in entry 25. Start with files 2378529 for the border and 2377632 for the expedition. For the Surgeon General’s final report, use RG 112 entry 26, file 156351. [S3]

In RG 165 start with file 9497 for War College material. Follow the transferred Maneuver Division correspondence into Military Intelligence Division entry 65, file 6274, and use file 13137 in that entry for the Columbus raid report. Use entry 63 for attaché reports, entry 152 for border censorship and the subject index in entry 310 for Historical Division unit files. [S3]

In RG 407 entry 37 use the Mexico country heading for weekly border summaries. Use the oversized 370.22 Mexican Expedition file for the final report and its Air Service, map and blueprint attachments. Use entry 16 for the compiled border and expedition casualty list. [S3]

## Return packet

Record the branch, unit or vessel and date range, then the record group, entry and file number or serial used. Mark which source places the individual, which places only the unit, and which only identifies a qualifying operation. If an entry number fails in the catalog, use [National Archives finding aids](us-national-archives-finding-aids-and-microfilm.md) to resolve the cited series. Use [service reconstruction](us-20th-century-military-service-reconstruction.md) to tie unit activity to the person’s dated presence. [S3]
