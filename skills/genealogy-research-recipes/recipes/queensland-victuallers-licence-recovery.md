# Trace a Queensland publican through victuallers' licences

Start with a deceased licensee, hotel or town and an approximate licensing year. Use [Australia and New Zealand record routing](australia-nz-record-routing.md) for other record types.

## Find the holder and premises

Search [MyHeritage's Queensland Licensed Victuallers index](https://www.myheritage.com/research/collection-20250/australia-queensland-licensed-victuallers-1900-1914) for gazette entries from July 1900 to July 1914. Copy the holder, publication date, place of issue, publication locator and any newspaper reference. If given, record coordinates as a town locator. Put the hotel or premises in its own field [S1 @2026-11-22] [S2 @2026-11-22].

Also check the State Library of Queensland's *Queensland Victuallers Licence index* in One Search. Use the name, hotel and district in the result to distinguish same-named holders. The index covers only some gazette transfers, so check the gazette for intervening changes when the same premises appears with different holders [S3 @2026-11-22] [S4 @2026-11-22].

## Verify the issue, transfer or application

Carry the indexed publication date and reference to the *Queensland Government Gazette*. For the indexed years, use the State Library's onsite copies or the Queensland State Archives guide to find the issue. Check the notice heading to distinguish an annual list from a transfer and record any separate date of grant or transfer [S2 @2026-11-22] [S3 @2026-11-22] [S5 @2026-11-22].

Follow the newspaper citation on the index entry if present. Use [historical newspaper search](historical-newspaper-section-search.md) to open the issue and read what the notice actually announces. An application to transfer a licence leaves the approval open. Compare it with the gazette result or licensing record before adding a change of holder to the timeline [S1] [S3].

## Change routes outside the index years

Before July 1900, check Appendix 1 of the Queensland State Archives hotel-records guide for annual gazette references. For records from 1914 onward, search the hotel or premises name in the Queensland State Archives' *Licensed Victuallers' Licence files*, series S17933, and check relevant district registers in the same guide. Use each series' dates and district to choose the item [S5 @2026-11-22].

Return each candidate's holder, premises, district, notice type, publication and event dates, and gazette page or archival reference. Report an index hit without the underlying page as an index lead.
