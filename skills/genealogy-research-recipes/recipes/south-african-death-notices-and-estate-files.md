# Recover a South African death notice inside an estate file

Open this recipe for a deceased person with a South African estate clue, or when a surviving civil death record leaves family relationships unresolved.

## Carry the estate reference into the packet

Search for the death notice with the estate papers. The community guide suggests checking multiple probate repositories, including the national archives [S1], [S5]. When using a National Automated Archival Information Retrieval System (NAAIRS) result, copy the depot, source code, volume, reference number, name and year. A probate index hit is a locator for the packet. Keep the depot with the complete reference when matching the result to an image group or archival inventory [S2].

For Cape Probate Records on FamilySearch, check the collection’s 1834–1989 scope. Use the matching index fields, including death date and spouse where present, and carry the probate number to the packet cover [S3 @2026-11-22].

For Bloemfontein, check the *Orange Free State, Estate Files, 1951–2006* image collection by year and surname initial. Keep the group’s actual year range and continue into later filings when the death-year group misses [S4 @2026-11-22].

## Read the death notice as an informant’s statement

Look for the death notice, will, inventory and distribution account within the packet. Extract recorded parents, spouses and children from the notice, and distinguish that report from the information on a civil death certificate. Preserve the informant and notice date where the form supplies them [S3], [S4].

## Return packet

Return the depot or court, estate file number, index and image locators, and each relationship with its document and informant. Use [probate packet inventory](probate-case-document-inventory.md) for the rest of the file and any later proceedings.
