# Source citation record

Use this reference to preserve a retrievable source record for the
[emigrant-origin packet](russian-empire-emigrant-origin-recovery.md).

## Preserve the locator

For each source you inspect, record:

- Your local record handle, such as `R1`.
- The holding repository and collection or series title.
- The record type and its date as written.
- The archive fund, inventory and file reference when present.
- The film or DGS identifier when present, in a separate field.
- The volume, page, passenger line or other item locator.
- The stable item URL or database identifier and date accessed.
- Saved image filenames, including continuation pages.

When you photograph material in a repository, also photograph the item's identifying pages and
containers. For a book, that means the title page. For a manuscript collection or vertical file,
it means the folder and the box-end label. Store these images with the target images so each one
keeps its collection, box and folder context. A label photo records the arrangement at the time
of your visit. It supports the citation but is not the citation. The
[archivist's advice](https://www.youtube.com/watch?v=zNVSOhlUmgI) motivates this step.

Keep the record's creation date separate from the date you viewed it. Preserve a documented
mapping between archive and film identifiers when available. An index entry and an inspected
original image have different retrieval paths; record which one you used.

A cropped image or transcription of one register entry often loses the page header, so it may
carry no year or place. While the full page is still open, record those values from the page
header or margin next to the crop's locators. A
[metrical-book screenshot collection discussion](https://forum.j-roots.info/viewtopic.php?f=181&t=4753)
motivates this step. A
[church-book transcription anecdote](https://forum.ahnenforschung.net/forum/thread/928-humoris-causa/)
shows the same loss when the date stands only in a heading or margin. Neither source supplies the
crop's archival signature, which still needs its own locator.

An archive can renumber an inventory, so file numbers in older extracts may no longer match its
current numbering. Record the file number as you found it, and mark whether it follows the old or
the current numbering. A
[parish-register extract discussion](https://rodgersforum.borda.ru/?1-29-0-00001515-000-0-0-1777199479=)
motivates this step: the poster notes that the numbers in his old extracts predate the renumbering
and labels one file number as new. It does not give a concordance or say when the renumbering
happened.

An entry number alone may not identify one entry when a register section runs more than one
numbering sequence. Cite the entry by file, leaf and side, section, sequence (in this example,
apparently one for males and one for females), number and date as written. A
[metrical-book transcription](https://rodgersforum.borda.ru/?1-7-0-00001326-000-0-0-1780129313=)
motivates this step. In one year's deaths section, two sequences interleave, so the same numbers
appear twice. The transcription does not explain the page layout. It does not show that every
parish or year numbered entries this way, so check the image before choosing the sequence.

When a printed local history cites archive files for a passage, cite the book and page as the
source you actually read. Record the author's fond, inventory, file and folio citation in its own
field as a lead to the original. Do not record it as an inspected source. Keep any hedge as given:
if a citation is marked only as a possible source, record it that way, and note whether the book
or the person excerpting it supplied the citation. A
[local-history excerpt thread](https://rodgersforum.borda.ru/?1-7-0-00000258-000-0-0-1776484154=)
shows both kinds of citation as posted by a forum member; it does not show which of them the book
prints itself. It does not establish that the cited files exist under those numbers today or that
they contain the paraphrased content.

Before you record a URL, test whether it reopens the specific entry in a new session. Some
search-result URLs expire, and some only reopen the search form. If so, save a capture of the
entry and record its locators in the fields above. If another site has a persistent page for the
same index entry, cite it as a second access path (see the two-provider rule below). The
[FreeReg example](https://www.youtube.com/watch?v=1OyoTZez5NA) and the
[GRO index example](https://www.youtube.com/watch?v=QuCBcmiFGFg) motivate this step. Neither
establishes how any site's links behave today.

If a cited web URL no longer resolves, try that original URL in the Wayback Machine.
If an archived copy opens, inspect what it actually contains and retain the original URL,
archived-capture URL and timestamp, and your access date separately. Cite the capture you
inspected; its timestamp is not the record's creation date. Missing captures or linked material
remain gaps.

The [historical lookup example](https://www.youtube.com/watch?v=OHDYkHli39k) motivates this
fallback. [Internet Archive's capture-data documentation](https://archive.org/help/wayback_api.php)
(updated 2013-09-24; text checked 2026-10-21) describes snapshot links and timestamps;
the citation and gap controls are Kinprove synthesis.

## Connect the citation to the evidence

Attach the citation or its local handle to each extracted observation. Preserve the literal
reading, its field role and any uncertain letters in the working packet. Link additional pages
and annotation or outcome records through their own locators.

If the tree offers reusable sources, reuse the matching book/collection bibliography
and put this entry's page, passage and item URL in its citation, using the fields above.
A bookmark helps reopen a site; it does not attach that citation to a supported fact.
Use the controls actually exposed to attach it only to facts the item supports, then
reopen each fact's source association to check the citation and its target. Keep the
repository (holder) distinct from the source's author or publisher.

Historical example: Family History Fanatics, [external-source citations](https://www.youtube.com/watch?v=0nbKvYysxn0)
(2023-02-06); the demonstrated screen controls are not a current interface contract.

Two providers can display the same underlying record. Preserve both access paths without
counting them as independent corroboration. Use
[evidence-proof-judgment.md](evidence-proof-judgment.md) to assess the observation's effect on
the research question, and [research-documentation.md](research-documentation.md) to retain
the search and report.

## Recheck shortened report references after editing

If a shortened note depends on the preceding note for its source, re-resolve that reference
after moving, inserting or combining notes. It must identify the intended source and actual
cited page or item. Replace an ambiguous reference with an explicit short citation, especially
after a note containing several sources; a repeated source can still cite a different page.
Keep the full source record intact. Family Locket's
[How to Shorten Citations](https://www.youtube.com/watch?v=DWdb7rQFpf0) (2023-11-11)
motivates this edit check without imposing an abbreviation, current style rule or software claim.

## Follow an earlier application cited as evidence

If a lineage application's generation-specific source area cites an earlier member's national
number instead of supporting documents, retain the reference and use it to identify and seek
the cited earlier application. Preserve locators and dates for both applications, then inspect
what the earlier source area actually supplies for the relevant generation. Keep a transcription
distinct from an inspected application image. The later application's date does not date its
underlying evidence; unavailable or uninformative earlier material remains an explicit gap.
Genealogy TV's [Sons of the American Revolution with Deborah Maddox](https://www.youtube.com/watch?v=EyHcF0-Xqyk)
(2025-04-11) motivates this handoff without guaranteeing access or proving the claimed lineage.
