# Source citation record

Use this reference to preserve a retrievable source record for any recipe's findings, for
example the [emigrant-origin packet](russian-empire-emigrant-origin-recovery.md).

## Contents

- Preserve the locator
- Format the citation
- Connect the citation to the evidence
- Recheck shortened report references after editing
- Follow an earlier application cited as evidence

## Preserve the locator

For each source you inspect, record:

- Your local record handle, such as `R1`.
- The holding repository and collection or series title.
- The record type and its date as written.
- Who created the record: the office, clergyman, clerk, compiler or author.
- The layer you consulted (original image, transcript, abstract or index), with its provider.
  When it is not the original, name the original it reproduces as well. Mills's
  [creator-first citation pattern](https://www.evidenceexplained.com/quicktips/citations-1-2-3-easy)
  and [layered citations](https://www.evidenceexplained.com/content/quicklesson-19-layered-citations-work-layered-clothing)
  motivate these two fields.
- The archive fund, inventory and file reference when present.
- The film or DGS identifier when present, in a separate field.
- The volume, page, passenger line or other item locator.
- The stable item URL or database identifier and date accessed.
- Saved image filenames, including continuation pages.

When you photograph material in a repository, also photograph the item's identifying pages and
containers. For a book, that means the title page. For a manuscript collection or vertical file,
it means the folder and the box-end label. Store these images with the target images so each one
keeps its collection, box and folder context. A label photo records the arrangement at the time
of your visit. It supports the citation but is not the citation. The
[archivist's advice](https://www.youtube.com/watch?v=zNVSOhlUmgI) motivates this step.

Keep the record's creation date separate from the date you viewed it. Preserve a documented
mapping between archive and film identifiers when available. An index entry and an inspected
original image have different retrieval paths; record which one you used.

When a U.S. National Archives finding aid identifies the series for a textual record, note the
record group and full entry number. Include the inventory or preliminary inventory number when
needed to identify the aid. Use the entry to recover the series title and any series identifier
the aid supplies. Check the series description against the record you inspected
[N8](https://www.archives.gov/files/research/foreign-policy/related-records/rg-76-international-boundaries.pdf).
In the finished citation, include the series and the item or file locator alongside the record
group and repository [N9](https://www.archives.gov/files/publications/general-info-leaflets/17-citing-records.pdf).
This step draws on Craig R. Scott's note-taking advice from the available excerpt
[N7](https://www.youtube.com/watch?v=pvr1z7Mchxw).

When saving a register crop, record the year and place from the full page alongside the file, folio and side. In one transcription the researcher copied every word of the entry but missed the date in the heading or margin. A headerless crop can leave the same gap [B2], [B3].

Copy an archival file number as cited and identify the numbering system. In one set of parish extracts the compiler says inventory 3 was renumbered and marks file 964 as new [B4]. No concordance accompanies the post. Check the dated catalogue or concordance for a matching record description before adopting a replacement number.

Cite a register entry by file, leaf and side, section, sequence, number and date as written. On leaf 36 of one 1818 deaths transcription, 1 January and 2 January both carry entry no. 1 [B5]. Inspect the register image to identify the columns before assigning a sequence to either entry.

Cite a printed local history by book and page, then copy its archival references into a separate field for follow-up. In a posted extract about the 1843 Shadrinsk district unrest, the contributor labels the accompanying source as possible [B6]. Preserve that qualification and check the printed page for who supplied the reference before recording the file as a lead.

Before you record a URL, test whether it reopens the specific entry in a new session. Some
search-result URLs expire, and some only reopen the search form. If so, save a capture of the
entry and record its locators in the fields above. If another site has a persistent page for the
same index entry, cite it as a second access path (see the two-provider rule below). The
[FreeReg example](https://www.youtube.com/watch?v=1OyoTZez5NA) and the
[GRO index example](https://www.youtube.com/watch?v=QuCBcmiFGFg) motivate this step. Neither
establishes how any site's links behave today.

If a cited web URL no longer resolves, recover a dated capture with the
[dead-citation procedure](research-documentation.md#recover-a-dated-page-behind-a-dead-citation).
Cite the capture you inspected, retaining the original URL, archived-capture URL and timestamp,
and your access date separately; its timestamp is not the record's creation date.

For a broken link copied from a book or article, try the exact URL in the Wayback Machine [B9]. Internet Archive’s published API example distinguishes the archived URL from its capture timestamp [B10]. Record both with the original URL and your access date.

When a volume has no printed page number, describe the entry by its actual internal structure, such as the year section, entry number and named event. Add the provider's image number with the provider and the route to that volume, rather than treating an image counter as a page printed in the source. Retain enough of the volume identification and entry context to locate it through another copy if the viewer's numbering changes [N1](https://genealogytipoftheday.com/index.php/2025/04/10/no-page-number/), [N2](https://www.evidenceexplained.com/node/1391).

For a filmed or digitized register, inspect the cover, spine or title frame and preserve its actual volume label. A catalogue title may describe an entire series rather than the specific volume you used. Record any mismatch explicitly; if the item has no title, supply a descriptive label as your own instead of silently assigning the series title to it [N3](https://genealogytipoftheday.com/index.php/2023/06/27/getting-all-the-details/), [N4](https://www.evidenceexplained.com/node/2230).

Binding does not establish publication. If the "book" is an unpublished typescript or manuscript deposited in a repository, identify its creator, title or supplied description, composition date when known, collection/item locator and holding institution with location. Do not invent a publisher or publication date from the binding or catalogue appearance [N5](https://genealogytipoftheday.com/index.php/2024/12/13/when-to-cite-a-specific-book/), [N6](https://answers.library.georgetown.edu/research/faq/228516).

## Format the citation

If you use *Evidence Explained*, adapt a chapter 3 template from the fourth edition or a
QuickCheck model from an earlier edition to the source and layer you actually inspected
[N10](https://genealogical.com/2024/02/05/author-elizabeth-shown-mills-talks-about-the-new-fourth-edition-of-evidence-explained-citing-history-sources-from-artifacts-to-cyberspace-by-elizabeth-shown-mills-cg-cg-fasg/).
When the editor provides a style sheet, use it to format the publication draft
[N11](https://www.ngsgenealogy.org/wp-content/uploads/2026/01/2025.12.8-NGSQ-style-sheet.pdf)
and retain the full locator in your working notes. The advice to use a model as a guide comes
from Craig R. Scott's video (partial access via supplied transcript excerpts)
[N7](https://www.youtube.com/watch?v=pvr1z7Mchxw).

## Connect the citation to the evidence

Attach the citation or its local handle to each extracted observation. Preserve the literal
reading, its field role and any uncertain letters in the working packet. Link additional pages
and annotation or outcome records through their own locators.

If the tree offers reusable sources, reuse the matching book/collection bibliography
and put this entry's page, passage and item URL in its citation, using the fields above.
A bookmark helps reopen a site; it does not attach that citation to a supported fact.
Use the controls actually exposed to attach it only to facts the item supports, then
reopen each fact's source association to check the citation and its target. Keep the
repository (holder) distinct from the source's author or publisher.

Historical example: Family History Fanatics, [external-source citations](https://www.youtube.com/watch?v=0nbKvYysxn0)
(2023-02-06); the demonstrated screen controls are not a current interface contract.

Two providers can display the same underlying record. Preserve both access paths without
counting them as independent corroboration. Use
[evidence-proof-judgment.md](evidence-proof-judgment.md) to assess the observation's effect on
the research question, and [research-documentation.md](research-documentation.md) to retain
the search and report.

### Diagnose attachment scope and retain the source image during correction

When an image appears in person media but not in a source preview, inspect the
person-media link and the source attachment separately. Record the expected
source, image/page locator, person and event. Image presence somewhere in the
file does not establish attachment to the source or support for a particular
fact. Resolve the association scope before treating a missing preview as a
missing file or copying media again.

Keep the correct source page and relevant passage visibly available while
correcting the related event. Use a supported pinned or locked source view, or
a separate visible image view if the application permits it. Confirm that
navigating to the event has not changed the displayed person, source or page.
If the available viewer blocks editing or cannot retain the image context,
record that limitation instead of assuming that a particular pane can detach.

Compare the old and proposed event values against that image, preserving the
source citation and other supported facts. After an authorized correction,
independently reopen both the source attachment and the person/event: verify
the intended image association, corrected value, citation, and preservation of
other facts and relationships. A visible image alone is not attachment or
successful-save evidence.

## Recheck shortened report references after editing

If a shortened note depends on the preceding note for its source, re-resolve that reference
after moving, inserting or combining notes. It must identify the intended source and actual
cited page or item. Replace an ambiguous reference with an explicit short citation, especially
after a note containing several sources; a repeated source can still cite a different page.
Keep the full source record intact. Family Locket's
[How to Shorten Citations](https://www.youtube.com/watch?v=DWdb7rQFpf0) (2023-11-11)
motivates this edit check without imposing an abbreviation, current style rule or software claim.

## Follow an earlier application cited as evidence

If a lineage application's generation-specific source area cites an earlier member's national
number instead of supporting documents, retain the reference and use it to identify and seek
the cited earlier application. Preserve locators and dates for both applications, then inspect
what the earlier source area actually supplies for the relevant generation. Keep a transcription
distinct from an inspected application image. The later application's date does not date its
underlying evidence; unavailable or uninformative earlier material remains an explicit gap.
Genealogy TV's [Sons of the American Revolution with Deborah Maddox](https://www.youtube.com/watch?v=EyHcF0-Xqyk)
(2025-04-11) motivates this handoff without guaranteeing access or proving the claimed lineage.
