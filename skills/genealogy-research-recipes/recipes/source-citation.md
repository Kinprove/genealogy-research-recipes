# Source citation record

Use this reference to preserve a retrievable source record for the
[emigrant-origin packet](russian-empire-emigrant-origin-recovery.md).

## Preserve the locator

For each source you inspect, record:

- Your local record handle, such as `R1`.
- The holding repository and collection or series title.
- The record type and its date as written.
- The archive fund, inventory and file reference when present.
- The film or DGS identifier when present, in a separate field.
- The volume, page, passenger line or other item locator.
- The stable item URL or database identifier and date accessed.
- Saved image filenames, including continuation pages.

When you photograph material in a repository, also photograph the item's identifying pages and
containers. For a book, that means the title page. For a manuscript collection or vertical file,
it means the folder and the box-end label. Store these images with the target images so each one
keeps its collection, box and folder context. A label photo records the arrangement at the time
of your visit. It supports the citation but is not the citation. The
[archivist's advice](https://www.youtube.com/watch?v=zNVSOhlUmgI) motivates this step.

Keep the record's creation date separate from the date you viewed it. Preserve a documented
mapping between archive and film identifiers when available. An index entry and an inspected
original image have different retrieval paths; record which one you used.

An archive can renumber an inventory, so file numbers in older extracts may no longer match its
current numbering. Record the file number as you found it, and mark whether it follows the old or
the current numbering. A
[parish-register extract discussion](https://rodgersforum.borda.ru/?1-29-0-00001515-000-0-0-1777199479=)
motivates this step: the poster notes that the numbers in his old extracts predate the renumbering
and labels one file number as new. It does not give a concordance or say when the renumbering
happened.

Before you record a URL, test whether it reopens the specific entry in a new session. Some
search-result URLs expire, and some only reopen the search form. If so, save a capture of the
entry and record its locators in the fields above. If another site has a persistent page for the
same index entry, cite it as a second access path (see the two-provider rule below). The
[FreeReg example](https://www.youtube.com/watch?v=1OyoTZez5NA) and the
[GRO index example](https://www.youtube.com/watch?v=QuCBcmiFGFg) motivate this step. Neither
establishes how any site's links behave today.

## Connect the citation to the evidence

Attach the citation or its local handle to each extracted observation. Preserve the literal
reading, its field role and any uncertain letters in the working packet. Link additional pages
and annotation or outcome records through their own locators.

If the tree offers reusable sources, reuse the matching book/collection bibliography
and put this entry's page, passage and item URL in its citation, using the fields above.
A bookmark helps reopen a site; it does not attach that citation to a supported fact.
Use the controls actually exposed to attach it only to facts the item supports, then
reopen each fact's source association to check the citation and its target. Keep the
repository (holder) distinct from the source's author or publisher.

Historical example: Family History Fanatics, [external-source citations](https://www.youtube.com/watch?v=0nbKvYysxn0)
(2023-02-06); the demonstrated screen controls are not a current interface contract.

Two providers can display the same underlying record. Preserve both access paths without
counting them as independent corroboration. Use
[evidence-proof-judgment.md](evidence-proof-judgment.md) to assess the observation's effect on
the research question, and [research-documentation.md](research-documentation.md) to retain
the search and report.
