# Organize historical photo scans by date evidence in Mylio Photos

Use Mylio Photos to keep uncertain original photo dates, review queues, event groups and a local backup for a scan project.

## Queue scans and enter a supported date

Open the scan folder and narrow it with QuickFilters, using an assigned scan keyword or embedded capture detail. For an existing LifeCalendar view, use a person or tag filter where it is available. Clear the filter before interpreting a missing item. [S1 @2026-11-21] [S3 @2026-11-21]

Give an uncertain photo only the precision the evidence supports. In the Info panel use the ellipsis beside Date Created/Shown to select Date Range, Season & Year, Year, Decade or Undated. Keep the evidence for the date with your research notes. When using seasons, check Settings → LifeCalendar for the season boundaries before comparing fuzzy dates with exact dates. [S1 @2026-11-21] [S2 @2026-11-21] [S4 @2026-11-21]

## Group a documented occasion and protect the library

Create a date- or folder-based Event for a documented occasion and inspect it in LifeCalendar. Keep an uncertain item’s own date range when placing it in the worklist. [S1 @2026-11-21] [S5 @2026-11-21]

If using Mylio Photos+, designate an external drive you control as a local Vault. Check that the Vault preserves full-resolution originals, metadata and the catalogue, including edits to date metadata. [S1 @2026-11-21] [S6 @2026-11-21]
