# Build and verify an Ancestry Pro Tools tree worklist

Use this recipe in an Ancestry tree you can edit, when you need a place or census worklist, a chart for a branch, or a way to triage possible tree errors. Read each Tree Checker flag against the underlying profile and its sources before editing.

## Create a locality or census worklist

According to the interviewee’s advice, use a locality-filtered list as a starting group for a one-place study, or use a common census tag to bring a set of profiles together. [S1†]

According to the interviewee, review the map’s numbered circles for a birth or marriage in an outlying place. [S1†]

Open **All People** and **Filters**. In **Events & places**, pick **Any Event** and the locality for a one-place worklist. For a census list, filter **Custom Tags** by the shared tag already attached to the candidate profiles. Record the filters with the result. A place match reflects an event recorded in the tree. [S2 @2026-11-18]

Open **Tree Mapper** to review mapped birth or marriage events. It opens on direct ancestors. Apply an event filter and open the numbered circles to examine outlying locations. Check the underlying place entry before using the circle as a locality lead. [S3 @2026-11-18]

## Generate a branch chart with known scope

According to the interviewee, use a branch chart as a visual reference and return to the underlying tree for the sources of its facts. [S1†]

**Privacy gate:** <!-- privacy-gate: export --> The selected branch’s names, events and relationships would leave Ancestry for the user’s device. Apply the [privacy gate](../SKILL.md#privacy-gate), including the retention rule.

In **Charts & reports**, choose a descendant report and change **Focus person** to the branch’s starting ancestor. Check the preview for the chosen branch and preferred parents. Download the branch chart to the user’s own device when a local copy is needed. [S4 @2026-11-18]

## Verify a flagged problem

According to the interviewee, check Tree Checker flags before changing the profile. [S1†]

Use the **Tree Checker** filters in **All People** to list flagged profiles. For one person, open the profile and click the circled exclamation mark at the upper right. Review the marked fact and evidence, then decide whether the flag points to a duplicate, an incorrect value or missing documentation. [S5 @2026-11-18]
