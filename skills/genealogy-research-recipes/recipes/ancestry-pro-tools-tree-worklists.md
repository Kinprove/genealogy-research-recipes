# Build and verify an Ancestry Pro Tools tree worklist

Use this recipe in an Ancestry tree you can edit, when you need a place or census worklist, a chart for a branch, or a way to triage possible tree errors. Read each Tree Checker flag against the underlying profile and its sources before editing.

## Create a locality or census worklist

According to the interviewee’s advice, use a locality-filtered list as a starting group for a one-place study, or use a common census tag to bring a set of profiles together. [S1†]

According to the interviewee, review the map’s numbered circles for a birth or marriage in an outlying place. [S1†]

In the intended tree, open **Find in tree** → **List of all people** → **Filters**. For a one-place worklist, select **Any Event** and the locality under **Events & places**. For a narrower search, choose an event such as birth and add a year or range, or use **Family line** to select paternal, maternal or end-of-line profiles. Record the active filters and work through the matches in Ancestry. A place match reflects an event recorded in the tree. [S7 @2026-11-22] [S2 @2026-11-22]

To group profiles in an unshared tree, open a person's card and choose **More options** → **Add tag** or **Edit tags**. Apply a standard label such as **Military Service** or a custom label for the census worklist. To retrieve tagged profiles, open **All People** → **Filters**, select the corresponding category under **MyTreeTags** and choose the tag. These tag filters are available without Pro Tools. [S6 @2026-11-22] [S2 @2026-11-22]

In the tree, open **View** → **Tree Mapper**. The map starts with direct ancestors. Set **Map Filters** to the family line, event, time or place you want to investigate. Check the active filters before comparing locations. Each numbered circle counts people with a matching event or fact in that area. Open the circle and check the underlying place entry before using it as a locality lead. [S3 @2026-11-22]

## Generate a branch chart with known scope

According to the interviewee, use a branch chart as a visual reference and return to the underlying tree for the sources of its facts. [S1†]

**Privacy gate:** <!-- privacy-gate: export --> The selected branch’s names, events and relationships would leave Ancestry for the user’s device. Apply the [privacy gate](../SKILL.md#privacy-gate), including the retention rule. A printout of the visible branch would send those profiles’ details to the user’s local printer.

Open the intended tree first, then choose **Charts and Reports** from **View**. Under **Document type**, use **Descendancy** for a line of descendants, **Register** to group descendants by family, **Ahnentafel** to trace ancestors, or **Family group sheet** for parents and their children. Set **Focus person** to the person the report should start from and choose the generation count when offered (2–7). Check the preview for the chosen branch and preferred parents. Download the branch chart to the user’s own device when a local copy is needed. [S4 @2026-11-22]

For a copy of the tree view, choose **Fan**, **Horizontal** or **Vertical** from **View** and bring the part you need into view. Use **More** → **Print** to print the visible part on the user's local printer or save it to the user's device if the print dialog offers a PDF option. Check the preview for the intended scope. [S8 @2026-11-22] [S4 @2026-11-22]

## Verify a flagged problem

According to the interviewee, check Tree Checker flags before changing the profile. [S1†]

Open the intended tree that you own or can edit and select its **Tree rating** or circled exclamation mark. The checker requires at least 50 people in the tree. If you use **Tree Checker** from **Pro Tools shortcuts** on the homepage, confirm the tree before reviewing the queue. The shortcut opens the last tree you viewed that you own or can edit. [S5 @2026-11-22]

In **All People** → **Filters**, use **Tree checker** to select a category such as possible duplicates or people with only tree sources. Combine it with **Family line** or **Events & places** to narrow the review. Work through the on-screen list. If it is empty, clear or broaden the filters before drawing a conclusion. [S2 @2026-11-22] [S5 @2026-11-22]

Open the flagged person's profile and use the circled exclamation mark or **Tools** → **Check for errors**. Review the profile and its sources to decide whether the flag points to a duplicate, an incorrect value or missing documentation. Leave unresolved gaps open. [S5 @2026-11-22]

Even with an empty **Possible Errors** list, check the record’s dates, places and relatives if it may have been attached to the wrong person with a similar name. [S5 @2026-11-22] [S9 @2026-11-22]

## Check which tree Tree Insights summarizes

Open the tree you intend to review, then go to the homepage and choose **More Pro Tools** → **Tree insights** → **Explore your insights**. Confirm the tree before using the rankings. Insights uses the last tree you viewed that you own or can edit, so open the next tree before returning to Insights. Use an outlier such as an unusually young marriage age as a lead to check the birth and marriage dates in the underlying profile. [S10 @2026-11-22]
