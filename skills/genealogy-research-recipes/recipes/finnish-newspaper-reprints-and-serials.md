# Recover related issues and editions of a historical Finnish newspaper item

Use this recipe when a historical Finnish newspaper item is abridged, points to earlier coverage or ends before the account is complete. Give a reprint and its source one evidence chain. Use [newspaper section search](historical-newspaper-section-search.md) to choose which part of a newspaper to read and [title coverage](newspaper-finder-title-coverage.md) to locate a missing issue.

## Trace a reprint or translation

Start with [Digi, the National Library of Finland’s digitized materials service](https://digi.kansalliskirjasto.fi/). Keep each edition’s newspaper title, date, issue and page in the search log [S1 @2026-11-22].

**Privacy gate:** <!-- privacy-gate: third-party-tool --> A search using a person’s name, an identifying place or an event sends those terms to the Digi digitized publications service. Apply the privacy gate in the skill instructions before submitting each identifying query.

Read the end credit and opening lines for the cited paper, an abbreviated title or an earlier item. Follow any reference back to the named issue. Search Finnish- and Swedish-language versions using the reported place, people and event when the translated headline differs. Compare versions field by field. When wording or a source credit shows one printing depends on another, cite both versions as one report [S2], [S3].

Check the source newspaper’s same-day and following issues for a correction and copy any identifying title the abridgment drops [S2]. Kyläkoski traces an Ilmarinen reprint back to an Östra Finland correction dated 9 October 1878 where she finds a revised amount and deposit location as well as the deceased’s former occupation [S2].

For a later article that refers back to a translated letter, follow the reference as its own link in the chain. Kyläkoski traces the 25 May 1844 opening of *Karhu-Pekasta ja Karhun taposta* to *Maamiehen ystävä*, 20 April 1844, page 4, and from there to the letter excerpt in *Wasa Tidning* [S3].

## Recover the serial run

List the issues in publication order and browse later issues across the year boundary. For a missing part, look beyond the next issue and record which issues you inspected. Kyläkoski’s *Kaksi renkiä* list for *Maamiehen ystävä* runs from 6 December 1845 to 17 January 1846 with gaps between its instalments [S4]. For *Isätön tukkipoika*, start with viewer page 2 of *Oulun Lehti*, issues 1–39 of 1886, in the order of Kyläkoski’s linked list [S5].

If a promised part is missing, search later issues for a notice explaining the break or announcing another version. Start *Kaksoiset* in *Oulun wiikko-sanomia* with issue 1 of 7 January 1860, viewer page 1, and issue 2 of 14 January, viewer page 2. Kyläkoski reproduces a notice in issue 43 about the missing continuations of both *Kaksoiset* and the Garibaldi biography, with a possible later version of *Kaksoiset* in another form [S7].

Read the opening editorial note and look for reader replies and staff comments in later issues before using a first-person narrator as evidence about the author. In the *Isätön tukkipoika* case, Kyläkoski records a reader taking the serial as autobiographical and the typesetter explicitly doubting that reading [S5].

Copy the editors’ stated changes when a serial’s opening describes what they altered. Attribute a spelling or wording choice to the author only to the extent the note supports it. For *Tuomio tuomarille ja kahden rakastajan ijäinen liitto*, use Kyläkoski’s list to start with *Kaiku*, issue 5 of 1878, page 2, for the editorial introduction. Keep the issue locators in the list when following the rest of the run [S6].

## Return the issue trail

Return the item as found, each recoverable printing or instalment in issue order, the source credit or phrase that connects it, and the fields added, omitted or corrected. Record the dateline, event date and issue date separately when the item supplies them. Flag gaps and state what the retrieved issues establish.
