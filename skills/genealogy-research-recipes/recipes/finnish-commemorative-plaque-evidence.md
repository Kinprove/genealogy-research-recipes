# Test what a Finnish commemorative plaque identifies

Use this recipe when a Finnish exterior plaque is cited as evidence for someone’s birth, residence or burial. The building holding the plaque can be a successor to the one the inscription commemorates.

## Find the installation and identify the commemoration

Search historical Finnish newspaper issues for *muistolaatta* and *muistotaulu* with the place, address or inscription words. Read the report for the person named when the plate gives only a title or description. Record the inscription’s date with the event it describes and record the installation date from a separate account of placement [S1]. Use [newspaper section search](historical-newspaper-section-search.md) to locate the notice or report.

Keep proposed wording open when a newspaper uses conditional language, solicits sponsors or prints the suggestion in a satirical column. Search for a later installation report even when a plaque with similar wording exists. Compare the material and mounting location with the earliest installation description before calling the plate original [S1].

## Check the building and the burial separately

The plaque described for Puutarhakatu 8 in Tampere marks Minna Canth’s birthplace on the successor building [S1], [S2], [S3]. Compare the plaque’s address with the footprint of the original structure and date the two buildings separately. Use [historical maps](historical-map-record-recovery.md) when the site or numbering changed.

For a name on a churchyard wall, keep the commemoration as its own observation. Use the [burial evidence recipe](burial-evidence-packet.md) to establish where the person was buried [S1].
